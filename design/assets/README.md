# Design assets

This is the canonical home for Cairo Bible visual design files.

- `icons/`: source app icon, web icon sizes, and SVG logo.
- `fonts/`: bundled brand fonts and their license files.
- `mockups/`: product and screen mockups.
- `app-store/`: submission artwork and generation notes.

Runtime paths point here through symlinks: `public/icons/`, `public/fonts/`, and the iOS asset catalog's `AppIcon.png`. Update the canonical files in this folder so the app and submission assets stay aligned.
